# Salesforce Interview Readiness Bootcamp – Day 4

## Lightning Web Components (LWC)

### 1. What is LWC?

Lightning Web Components (LWC) is Salesforce's modern user interface framework built using standard web technologies such as HTML, JavaScript, and CSS. It is used to create fast, reusable, and maintainable components for Salesforce applications.

---

### 2. What did you build?

I created a Lightning Web Component named **placementHome** for a Placement Management System. The component includes:

- Welcome to Vishnu Placement Portal
- Student Name
- Roll Number
- Department
- Automatically generated current date
- Number of Companies
- Number of Jobs
- Applications Submitted
- Apply button to change the application status from **Not Applied** to **Applied**
- Data binding using JavaScript variables
- Event handling using a Lightning Button

---

### 3. Which file contains HTML?

The **placementHome.html** file contains the HTML template that defines the user interface, including text, buttons, and displayed information.

---

### 4. Which file contains JavaScript?

The **placementHome.js** file contains the component logic, variables, event handling, data binding, and button click functionality.
