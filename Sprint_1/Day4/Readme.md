# Salesforce Interview Readiness Bootcamp – Day 4
## Lightning Web Components (LWC)

### 📌 Project Overview
This project is part of the Salesforce Interview Readiness Bootcamp – Day 4. The objective was to learn the fundamentals of Lightning Web Components (LWC) by creating a simple Placement Portal component using HTML and JavaScript.

---

## 📂 Source Code

The project contains the following source files:

- `placementHome.html` – Defines the user interface of the component.
- `placementHome.js` – Contains JavaScript logic, variables, data binding, and event handling.
- `placementHome.js-meta.xml` – Exposes the component to Lightning App Builder.
- `Readme.md` – Project documentation.

## ⚠️ Challenges

While working on this assignment, I encountered the following challenges:

- Understanding the structure of an LWC component.
- Learning how data binding works between JavaScript and HTML.
- Deploying the component to the Salesforce Org.
- Configuring the component on a Lightning App Page.
- Managing Git and GitHub while submitting only the required project files.

These challenges were resolved through debugging, testing, and following Salesforce development best practices.
